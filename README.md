# Project Phoenix

A work-in-progress enterprise conversational AI platform built to explore how modern backend systems integrate with conversational interfaces.

The goal of this project is not just to build a chatbot, but to understand the complete software development lifecycle—from identifying a business problem to designing, implementing, testing, and deploying a production-style application.

---

## Why I'm Building This

Most chatbot tutorials stop after connecting a few intents and returning static responses.

I wanted to build something closer to what an engineering team might work on:

- A maintainable backend
- Proper API design
- Secure authentication
- Database integration
- Dialogflow CX webhook integration
- Cloud deployment
- Documentation from Day 1

This repository documents that journey.
