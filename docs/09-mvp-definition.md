# MVP Definition

## Purpose

The objective of the Minimum Viable Product (MVP) is to demonstrate a complete end-to-end enterprise conversational AI workflow while keeping implementation manageable.

---

## Included

### Backend

- Spring Boot
- REST APIs
- JWT Authentication
- Validation
- Exception Handling

---

### Database

- PostgreSQL
- Conversation storage
- User management

---

### Conversational AI

- Dialogflow CX
- Intent detection
- Webhooks

---

### Frontend

- React Dashboard
- Login
- Conversation History
- Basic Analytics

---

### Deployment

- Docker
- Google Cloud Run

---

## Excluded

- Voice interaction
- Multi-language support
- Live chat agents
- AI-generated analytics
- Mobile applications
- Multi-tenant support

---

## MVP Success Criteria

The MVP will be considered complete when:

- Authentication works.
- Chatbot communicates with backend services.
- Conversations are stored.
- Dashboard displays conversation history.
- Application is deployed on Google Cloud Run.
