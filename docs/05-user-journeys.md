# User Journey

## Scenario

A customer wants information using the chatbot.

---

Customer opens website

↓

Launches chatbot

↓

Types a question

↓

Dialogflow CX detects intent

↓

Webhook invokes Spring Boot API

↓

Backend retrieves information

↓

PostgreSQL returns data

↓

Backend formats response

↓

Dialogflow sends response

↓

Customer receives answer

↓

Conversation stored for analytics
