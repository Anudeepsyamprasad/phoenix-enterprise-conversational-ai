# Backend

This module contains the backend application for Project Phoenix.

The backend is responsible for exposing REST APIs, handling business logic, integrating with Dialogflow CX webhooks, and communicating with the PostgreSQL database.

## Planned Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Maven

## Planned Modules

- Authentication
- Conversation APIs
- User Management
- Analytics
- Dialogflow Webhooks
